Turn your photos into bold GTA-poster-style multi-panel cover art, exported as a PNG to share. Vice Lights Cover Atelier is a static offline web app: upload 1–4 photos (or use the two built-in samples), pick one of 6 layouts — Hero, Split, Trio, Grid, Diagonal Split, and Poster — apply one of 4 one-click templates, choose from 6 colour grades (Sunset, Neon Night, Golden Hour, Mono Noir, Vice Pink, Teal Vice) and 3 lettering styles (Bold Outline, Gradient Block, Neon Glow), then crop and position each photo per panel (drag to pan, scroll to zoom, fit/fill, flip, tilt) and export in 1080×1080, 1080×1350, or 1920×1080. Everything runs in your browser; photos are never uploaded.

## How to run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network requests — every file the app loads lives under `app/`.
